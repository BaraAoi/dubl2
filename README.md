## Запуск

Игра статическая: HTML + CSS + ES-модуль. Никакой сборки не требуется.

**GitHub Pages**

1. Settings → Pages → Source: `Deploy from a branch`.
2. Branch: `main`, папка `/ (root)`.
3. Откройте `https://<пользователь>.github.io/dubl2/`.

**Локально** (ES-модули и импорт-карта не работают по `file://`):

```bash
python3 -m http.server 8080
# затем откройте http://localhost:8080
```

Требуется WebGL и браузер с поддержкой Pointer Lock. Для микрофона нужен `https://`
или `localhost` — браузеры не выдают доступ к записи с незащищённого адреса.

## Управление

| Клавиша | Действие |
| --- | --- |
| `W` `A` `S` `D` / стрелки | Движение |
| `Shift` | Бег (расходует выносливость) |
| Мышь | Обзор |
| `Esc` | Пауза и освобождение курсора |

Выносливость восстанавливается в покое. При полном истощении включается
«одышка»: бег блокируется, пока шкала не восстановится примерно до 28%.

## Что реализовано в Части I

**Интерфейс (полностью на русском)**

- Главное меню в стиле ржавого терминала: CRT-развёртка, зерно, сканлайны,
  глитч заголовка, бегущая строка служебных объявлений и бортовые часы.
- Кнопки: **Создать лобби**, **Подключиться**, **Настройки**.
- Настройки: ползунок **Громкость игры**, ползунок чувствительности мыши,
  **визуальный индикатор уровня микрофона** (28 сегментов, шкала дБ, метка пика).
- Игровой HUD: прицел, шкала **выносливости** (с предупреждением и истощением),
  маршрут вагона, код сеанса, подсказки управления.
- Экран паузы: продолжить, настройки, выход в меню.
- Загрузочный экран с логами системы и отдельным сообщением, если CDN с Three.js
  недоступен.

**Мир (Three.js)**

- Длинный закрытый вагон 3.8 × 3.05 × 32 м: доски, ковровая дорожка, деревянные
  скамьи с подголовниками, багажные полки с чемоданами, поручни и подвесные петли,
  тамбурные двери с иллюминаторами, часы, показывающие полночь.
- Пять источников света: главная лампа с нерегулярным мерцанием (тени 512²),
  две боковые лампы, красная лампа тамбура и зелёная — у выхода.
- Процедурные текстуры, генерируемые на `<canvas>`: дерево, облупившаяся краска,
  ткань, ковёр, ночной пейзаж с дождём, плакаты «Правила проезда», «Расписание»,
  «Не спи», надпись «НЕ ОБОРАЧИВАЙСЯ» и часы. Внешних ассетов нет.
- Туман, пыль в воздухе, покачивание подвесных петель, микровибрация состава.

**Игрок**

- `PointerLockControls` из Three.js, покачивание камеры при ходьбе и беге,
  лёгкий FOV-эффект на бегу.
- Ускорение/торможение, скольжение вдоль стен, коллизии по осям с AABB скамей,
  багажа и стен вагона.
- Защита от «прыжка» камеры в момент захвата курсора.
- Если браузер не дал Pointer Lock, игра не зависает: открывается экран входа.

**Звук**

- Синтезированные Web Audio: низкочастотный гул состава, стук колёс,
  шаги по деревянному полу, щелчки интерфейса. Никаких аудиофайлов.
- Громкость и чувствительность сохраняются в `localStorage`.
- Микрофон только анализируется (AnalyserNode) и **никуда не передаётся**;
  после закрытия настроек дорожка останавливается.

## Структура

```
index.html   — разметка экранов, стили терминала, import map Three.js
game.js      — весь игровой код, один ES-модуль
```

`game.js` разделён на независимые модули:

| Модуль | Назначение |
| --- | --- |
| `CONFIG` | Все настраиваемые константы (вагон, игрок, сеть) |
| `EventBus` | Слабая связь UI ↔ игра ↔ сеть |
| `SettingsStore` | Чтение/запись настроек в `localStorage` |
| `AudioManager` | Эмбиент, шаги, UI-звуки, анализ микрофона |
| `TextureFactory` | Процедурные canvas-текстуры |
| `TrainCar` | Геометрия, материалы, свет, анимация вагона |
| `PlayerController` | Pointer Lock, движение, выносливость, коллизии |
| `NetworkManager` | **Заглушка Части II** — уже подключена к UI и шине |
| `UIManager` | Экраны, HUD, настройки, микрофон, тосты |
| `Game` | Сборка сцены, состояния, главный цикл |

Публичный объект для отладки и для модуля сети:

```js
window.MidnightExpress.game      // экземпляр Game
window.MidnightExpress.network   // NetworkManager
window.MidnightExpress.modules   // все классы
```

## Точки расширения для Части II

- `NetworkManager.createLobby()` уже выдаёт код сеанса и эмитит
  `network:lobbyCreated`; UI показывает его в HUD и на экране паузы.
- `NetworkManager.joinLobby(code)` возвращает единый результат
  `{ ok, reason, message }` — достаточно заменить тело метода транспортом.
- `PlayerController.getNetworkState()` отдаёт позицию, углы обзора и выносливость
  (20 тиков/с через `NetworkManager.update`).
- `PlayerController.reset(spawn)` принимает стартовую точку от хоста.
- События шины: `session:started`, `session:ended`, `player:lock`, `player:unlock`,
  `player:stamina`, `network:tick`.
- `TrainCar.colliders` — массив AABB; его можно сериализовать и передать клиентам.
- Готовые модели для удалённых игроков: `NetworkManager` уже транслирует
  `network:tick` с локальным снимком состояния.

## Известные ограничения

- На мобильных устройствах меню и настройки адаптивны, но для управления
  нужны клавиатура и мышь (Pointer Lock). Мобильным игрокам показывается
  предупреждение.
- Для WebGL нужен современный браузер; при недоступности CDN загрузочный экран
  сообщит об ошибке и предложит перезагрузку.
