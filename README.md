> Ночной состав №06 не значится ни в одном расписании.

## Запуск

Игра статическая: HTML + CSS + ES-модуль. Никакой сборки не требуется.

**GitHub Pages**

1. Settings → Pages → Source: `Deploy from a branch`.
2. Branch: `main`, папка `/ (root)`.
3. Откройте `https://<пользователь>.github.io/dubl2/`.

**Локально** (ES-модули и импорт-карта не работают по `file://`):

```bash
python3 -m http.server 8080
# затем откройте http://localhost:8080
```

Требуется WebGL и браузер с поддержкой Pointer Lock. Для микрофона нужен `https://`
или `localhost` — браузеры не выдают доступ к записи с незащищённого адреса.

## Игра вдвоём (и до шести)

1. Хост нажимает **«Создать лобби»**. Открывается экран лобби с кодом из пяти
   символов, например `Код лобби: J4JJV`. Код можно скопировать одной кнопкой.
2. Остальные нажимают **«Подключиться»**, вводят код и попадают в тот же тамбур.
3. Когда все собрались, каждый нажимает **«Войти в салон»** — курсор захватывается,
   и пассажир оказывается в вагоне.
4. В салоне видно остальных: капсула с позывным над головой. Чем ближе человек,
   тем громче его голос.

Ограничения лобби: **2–6 игроков**, один хост. Хост — обычный участник, а не сервер:
его вкладка раздаёт список экипажа и пересылает координаты. Если хост закрыл
вкладку или потерял связь, остальные видят экран **«Хост покинул вагон»** и
возвращаются в меню.

## Управление

| Клавиша | Действие |
| --- | --- |
| `W` `A` `S` `D` / стрелки | Движение |
| `Shift` | Бег (расходует выносливость) |
| Мышь | Обзор |
| `V` | Рация: удерживать, чтобы говорить (режим «Рация») |
| `Esc` | Пауза и освобождение курсора |

Выносливость восстанавливается в покое. При полном истощении включается
«одышка»: бег блокируется, пока шкала не восстановится примерно до 28%.

## Голосовой чат

- При старте игра **сразу запрашивает разрешение на микрофон** (браузер покажет
  стандартное окно). Сам поток не удерживается: он поднимается в лобби и
  освобождается при выходе.
- Два режима в настройках:
  - **Открытый микрофон** — голос идёт постоянно;
  - **Рация · V** — микрофон молчит, пока удерживается `V`.
- Звук **позиционный**: каждый собеседник подключён к `THREE.PositionalAudio`
  с моделью `inverse`, `refDistance = 2.2`, `maxDistance = 16`. Дополнительно
  громкость плавно гасится вручную: с 9.5 м до 14 м она уходит в ноль, и дальше
  человек не слышен совсем (проверено в тесте: 7.3 м → громкость 1.0,
  19.6 м → 0.0).
- Поверх голоса — «рация»: полосовой фильтр 280 Гц … 3.4 кГц, подъём разборчивости
  на 1.75 кГц, мягкая сатурация и еле слышный шум эфира, который появляется,
  только когда собеседник говорит.
- Пока игрок не передаёт голос, от него всё равно уходит «тихий» поток, чтобы
  WebRTC-канал не пересоздавался при каждом включении рации.
- Наушники обязательны: при открытом микрофоне без них будет эхо.

## Сеть: как это устроено

```
        PeerJS Cloud (0.peerjs.com)  — только сигнализация
                    │
        ┌───────────┴───────────┐
        │                       │
     ХОСТ  ◄── WebRTC Data ──► Гость
        ▲      (20 Гц)          │
        └────── WebRTC Media ───┘   голос, напрямую
```

- **Топология — звезда.** Хост держит DataConnection с каждым гостем и
  пересылает их координаты остальным, поэтому все видят всех, а игровой сервер
  не нужен.
- **Код лобби** — это peer id `nv06-XXXXX`. Алфавит из 32 символов без похожих
  друг на друга (`I`, `O`, `0`, `1` исключены). При коллизии хост генерирует новый код.
- **Синхронизация.** Позиция `x/y/z`, поворот по `yaw` и флаг «в вагоне»
  отправляются 20 раз в секунду. Удалённые капсулы интерполируются с задержкой
  ~110 мс; при телепорте-скачке больше 6 м буфер сбрасывается.
- **Пульс.** Раз в секунду уходит `ping` и дублируется состояние. Пульс живёт на
  `setInterval`, а не на `requestAnimationFrame`, поэтому фоновая вкладка не
  «растворяется» для остальных. Молчание дольше 20 с — потеря связи.
- **Переподключение.** При обрыве сигнального сокета PeerJS переподключается
  сам; при возврате сети срабатывает `online`-событие.
- **Выход.** Хост при выходе рассылает `{ t: 'close' }`, гость — `{ t: 'bye' }`;
  вторая сторона сразу убирает капсулу, голосовой канал и обновляет список.

### Сигнальный сервер

По умолчанию используется публичный PeerJS Cloud (`0.peerjs.com:443`, `key: peerjs`).
Он бесплатный и подходит для небольших сессий, но может быть медленным.

Свой сервер (например, на VPS):

```bash
npm install -g peer
peerjs --port 9000 --path / --key peerjs
```

и подмените конфиг **до** загрузки `game.js`:

```html
<script>
  window.__MX_PEER_SIGNALING__ = {
    host: 'peer.example.com',
    port: 443,
    secure: true,
    path: '/',
    key: 'peerjs'
  };
</script>
```

Или отредактируйте `CONFIG.network.signaling` в `game.js`.

### TURN для строгих NAT

По умолчанию в конфиге только STUN. Если у игрока симметричный NAT или
корпоративный файрвол, P2P-канал не поднимется — игра покажет предупреждение
«нужен TURN-сервер». Добавьте свой TURN в `CONFIG.network.iceServers`:

```js
{ urls: 'turn:turn.example.com:3478', username: 'user', credential: 'secret' }
```

## Что реализовано

### Часть II — сеть и голос

**Лобби**

- Экран «Сетевой тамбур»: крупный код, кнопка копирования, статус канала,
  список экипажа на 6 мест (хост, «вы», пинг), чип голосового канала.
- Вход по коду: 5 символов, автоuppercase, фильтрация мусора, понятные ошибки
  («лобби не найдено», «вагон заполнен», «хост не отвечает»).
- Кнопки «Покинуть лобби» / «Войти в салон», счётчик экипажа в HUD и на паузе.
- Экран «Хост покинул вагон» с возвратом в меню.

**Синхронизация**

- 20 Гц, состояние `x / y / z / yaw` + флаг нахождения в вагоне.
- Капсулы (CapsuleGeometry) с головой, «плечами», светящимся визором и
  кольцом на полу; позывной — спрайт с canvas-текстурой, индикатор речи
  и статус «НЕТ СВЯЗИ».
- Плавная интерполяция, отбрасывание скачков, затухание таблички в тумане.
- Тосты «вошёл в вагон» / «покинул вагон» / «связь потеряна».

**Голос**

- PeerJS MediaConnection на каждого собеседника, инициатор выбирается
  детерминированно (меньший peer id), второй подхватывает через 6 с.
- `THREE.PositionalAudio` + `PannerNode` (HRTF), ручное затухание до нуля.
- Радио-фильтр, шум эфира, индикаторы речи над капсулой и в HUD.
- Настройки: вкл/выкл передачи, режим «Открытый / Рация · V», позывной.
- Микрофон общий для проверки в настройках и для чата (ref-counted), корректно
  освобождается и восстанавливается после системного отключения.

### Часть I — мир и управление

**Интерфейс (полностью на русском)**

- Главное меню в стиле ржавого терминала: CRT-развёртка, зерно, сканлайны,
  глитч заголовка, бегущая строка служебных объявлений и бортовые часы.
- Кнопки: **Создать лобби**, **Подключиться**, **Настройки**.
- Настройки: ползунок **Громкость игры**, ползунок чувствительности мыши,
  **визуальный индикатор уровня микрофона** (28 сегментов, шкала дБ, метка пика).
- Игровой HUD: прицел, шкала **выносливости** (с предупреждением и истощением),
  маршрут вагона, код сеанса, экипаж, пинг, состояние голоса, подсказки.
- Экран паузы: продолжить, настройки, выход в меню.
- Загрузочный экран с логами системы и отдельным сообщением, если CDN с Three.js
  недоступен.

**Мир (Three.js)**

- Длинный закрытый вагон 3.8 × 3.05 × 32 м: доски, ковровая дорожка, деревянные
  скамьи с подголовниками, багажные полки с чемоданами, поручни и подвесные петли,
  тамбурные двери с иллюминаторами, часы, показывающие полночь.
- Пять источников света: главная лампа с нерегулярным мерцанием (тени 512²),
  две боковые лампы, красная лампа тамбура и зелёная — у выхода.
- Процедурные текстуры, генерируемые на `<canvas>`: дерево, облупившаяся краска,
  ткань, ковёр, ночной пейзаж с дождём, плакаты «Правила проезда», «Расписание»,
  «Не спи», надпись «НЕ ОБОРАЧИВАЙСЯ» и часы. Внешних ассетов нет.
- Туман, пыль в воздухе, покачивание подвесных петель, микровибрация состава.

**Игрок**

- `PointerLockControls` из Three.js, покачивание камеры при ходьбе и беге,
  лёгкий FOV-эффект на бегу.
- Ускорение/торможение, скольжение вдоль стен, коллизии по осям с AABB скамей,
  багажа и стен вагона.
- Защита от «прыжка» камеры в момент захвата курсора.
- Если браузер не дал Pointer Lock, игра не зависает: открывается экран входа.

**Звук**

- Синтезированные Web Audio: низкочастотный гул состава, стук колёс,
  шаги по деревянному полу, щелчки интерфейса. Никаких аудиофайлов.
- Громкость, чувствительность, режим голоса и позывной сохраняются в `localStorage`.

## Структура

```
index.html   — разметка экранов, стили терминала, import map Three.js, PeerJS
game.js      — весь игровой код, один ES-модуль
```

`game.js` разделён на независимые модули:

| Модуль | Назначение |
| --- | --- |
| `CONFIG` | Все настраиваемые константы (вагон, игрок, сеть, голос) |
| `EventBus` | Слабая связь UI ↔ игра ↔ сеть |
| `SettingsStore` | Чтение/запись настроек в `localStorage` |
| `AudioManager` | Эмбиент, шаги, UI-звуки, общий микрофон (ref-counted) |
| `TextureFactory` | Процедурные canvas-текстуры |
| `TrainCar` | Геометрия, материалы, свет, анимация вагона |
| `PlayerController` | Pointer Lock, движение, выносливость, коллизии |
| `NetworkManager` | PeerJS: лобби, роутинг данных, пульс, реконнект |
| `RemotePlayers` | Капсулы, позывные, интерполяция |
| `VoiceChat` | WebRTC-голос, позиционное аудио, «рация», PTT |
| `UIManager` | Экраны, лобби, HUD, настройки, микрофон, тосты |
| `Game` | Сборка сцены, состояния, главный цикл |

Публичный объект для отладки:

```js
window.MidnightExpress.game            // экземпляр Game
window.MidnightExpress.network         // NetworkManager
window.MidnightExpress.voice           // VoiceChat
window.MidnightExpress.remotePlayers   // RemotePlayers
window.MidnightExpress.modules         // все классы
window.MidnightExpress.config          // CONFIG
```

Полезные вызовы для ручной проверки:

```js
MidnightExpress.game.createLobby()        // открыть лобби
MidnightExpress.game.joinSession(result)  // войти по результату joinLobby
MidnightExpress.network.getPlayers()      // список экипажа
MidnightExpress.game.voice.peers          // голосовые каналы
```

## Известные ограничения

- На мобильных устройствах меню и настройки адаптивны, но для управления
  нужны клавиатура и мышь (Pointer Lock). Мобильным игрокам показывается
  предупреждение.
- Для WebGL нужен современный браузер; при недоступности CDN загрузочный экран
  сообщит об ошибке и предложит перезагрузку.
- Публичный PeerJS Cloud не гарантирует стабильность; для регулярных сессий
  поднимайте свой `peerjs-server` (см. выше).
- Без TURN-сервера часть игроков за строгим NAT не сможет подключиться к голосу.
- Хост — точка отказа: его уход закрывает лобби (миграции хоста в Части II нет).
- Голос передаётся напрямую между браузерами; запись нигде не сохраняется
  и не проходит через игровой сервер.
